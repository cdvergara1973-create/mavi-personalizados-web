# MAVI Personalizados

Sitio web oficial de MAVI Personalizados, desarrollado con Next.js y preparado
para publicarse automáticamente desde GitHub en Vercel.

## Productos

- Poleras
- Polerones
- Gorras
- Chapitas
- Tazas
- Tazones
- Shoperos
- Toppers de torta

## Desarrollo local

Requiere Node.js 22 o superior.

```bash
npm install
npm run dev
```

La web estará disponible en `http://localhost:3000`.

## Validación

```bash
npm run build
```

## Publicación

Al conectar este repositorio con Vercel, cada cambio enviado a la rama `main`
genera una nueva publicación. Las ramas adicionales pueden utilizarse para
obtener vistas previas antes de pasar los cambios a producción.
